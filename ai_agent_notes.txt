Query: "Find PM of India and send email to abc@gmail.com"
-------------------------------------------------------

Step 1: app.py
        → session_id banaya
        → multi_agent_graph.invoke() call kiya

Step 2: memory_retrieval_node
        → pehle ki baatein memory se li
        → register me likhi

Step 3: manager_node
        → LLM se poocha: "kya karna hai?"
        → LLM bola: "research,email"
        → task_queue = ["research", "email"]

Step 4: router_node
        → queue: ["research", "email"]
        → "research" uthaya
        → current_task = "research"
        → queue = ["email"]

Step 5: research_agent_node
        → search_tool se PM of India search kiya
        → research_result = "Narendra Modi is PM..."
        → router ko wapas gaya

Step 6: router_node
        → queue: ["email"]
        → "email" uthaya
        → current_task = "email"
        → queue = []

Step 7: email_agent_node
        → research_result li (Narendra Modi...)
        → email_tool se abc@gmail.com pe bheja
        → email_result = "Email Sent Successfully"
        → router ko wapas gaya

Step 8: router_node
        → queue: []  (khaali!)
        → current_task = "done"
        → final_response ko bheja

Step 9: final_response_node
        → research_result + email_result jode
        → final_answer = "Narendra Modi is PM...\n\nEmail Sent"

Step 10: app.py
         → final_answer mila
         → User ko dikhaya ✅
